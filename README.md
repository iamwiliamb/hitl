# Human Review Prototype

This is an interactive HTML, CSS, and JavaScript prototype implementing the Human Review product and design specifications.

## Launch Instructions
1. Extract this zip file.
2. Open `index.html` directly in any modern desktop or tablet web browser. No build steps or local servers are required.
3. To add your own designs, simply replace the placeholder images inside `assets/scenarios/ic-02/` and update `prototype-manifest.json`.

## Keyboard Controls and Accessibility
*   `Tab` navigates through UI components and click hotspots.
*   `Enter` triggers action on focused hotspots. 

## Known Limitations
*   All people, claim numbers, and data are fictional synthetic data; this is not connected to a live backend API.
